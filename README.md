# E-Commerce Website Project

A conversion-focused e-commerce website built to demonstrate modern front-end development, UX/UI best practices, and production-ready project structure.

## Live Demo
- Website: [https://ecorm11.netlify.app/]
- Portfolio: https://xoladevs.netlify.app

## Key Features
- Product listing and product details
- Cart and checkout flow (UI + logic)
- Responsive mobile-first UI
- Performance-focused front-end structure
- SEO-friendly structure (metadata, semantic HTML)
- Clean component/module structure (where applicable)

## Tech Stack
- HTML, CSS, JavaScript
- (Optional) Supabase / API integrations
- (Optional) Payment integration approach (documented)

## How to Run Locally
1. Download/clone this repo
2. Open `index.html` (static)  
   OR if you have a dev server:
   - `npm install`
   - `npm run dev`
